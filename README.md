# 30期走势规律实验室

双色球 / 大乐透 / 快乐8 / 福彩3D —— 固定「最近 30 期」窗口的走势形态研究与复盘修正工具。

- 走势形态：和值 / 奇偶 / 质合 / 大小 / 区间 / 012路 / 重号邻号斜跳 / 冷热遗漏 → 一阶马尔可夫转移预测下期形态 → 形态约束合成推荐
- 复盘修正：预测存档 → 开奖自动核对 → 冷热/遗漏/共现三维度走前归因校准（权重夹在 0.6–1.4）
- 诚实声明：开奖为独立随机事件，任何统计整理都不能提高中奖概率；未满 18 周岁禁止购彩，理性购彩

数据每晚由 GitHub Actions 自动更新（来源：中国福彩 / 体彩官方公开接口）。

## 本地运行

```bash
python -X utf8 server.py
```

## 数据更新

```bash
python -X utf8 gen_snapshot.py   # 手动刷新快照（正常由 Actions 每晚自动执行）
```
